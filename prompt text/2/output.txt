v1.1 is built, verified and released. Every chapter now has its own page with a summary box and a notes box under it, what you type saves as you go, and Export and Import carry it between sessions. It is on main, so Cloudflare will deploy it.

**How it works.** The front page is still the chapter list, now with the Introduction added as its own page too, so there are 58 pages in all. Click a chapter and it opens on its own page with the part name, the chapter title, a Summary box, a Notes box beneath it, and links to the previous and next chapter. Each page has its own address, so a bookmark or the back button lands on the chapter you were on. Text saves to the browser as you type, with a "Saved" stamp under the boxes, and the list shows a small summary or notes mark beside every chapter you have written on plus a count of how many pages have something in them.

**Export and Import.** Export is in the header on every page. It downloads a dated JSON file holding everything you have written. Import reads such a file back in. It merges rather than wipes: a chapter from the file replaces the same chapter here unless what is here was written more recently, and chapters the file does not mention are left alone. The status message tells you how many pages came in and whether any newer ones were kept. A file that is not a JSON export, or has no chapter entries, is refused with a message and nothing changes.

**What to know.** Everything lives in your browser's local storage, which stays on that device and that browser. Nothing is sent anywhere. So the habit to keep is export at the end of a session, and import at the start of the next one if you are on a different device or the browser was cleared. The page is one self-contained HTML file, styles and script inline, so it also works opened straight from disk. The styling is only what the boxes need to be usable, full width and comfortable to type in. The look is still yours to ask for.
