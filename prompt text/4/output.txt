v1.3 is built, verified and released. Each chapter page now opens with a chapter type, set with one click, and it saves, exports and imports with everything else.

**The choice.** It sits under the headline and above the Summary box, labelled Chapter type, with three options because you asked for the two kinds plus neither. Overview is for a chapter that introduces a run of chapters, like the operating expenses chapter in your screenshot. Metric is for a chapter with direct information on one metric. Background is for information only, with no metric, such as the Introduction. They are a set of radio buttons rather than a checkbox, since exactly one of the three applies to any chapter, and the chosen one fills in ink the way the open tab does. Choosing saves at once, with the Saved stamp under the boxes.

**Where it shows.** The contents page tags each chapter with its type in teal beside the claret summary and notes marks, so you can scan which chapters are overviews and which carry a metric. The dot on a chapter's tab and the count of pages written still mean text, not a type on its own. A type with nothing written is kept, so you can classify chapters first and write later.

**Exports.** The export file gains a type on each entry and nothing else changes, so an export from the previous versions still imports as it was, with no type set. Importing a file with types restores them, and the newer-text-wins rule is unchanged. A type the page does not know is dropped on import.

**Verified.** The wrangler dry-run passed. A headless Chromium run drove the page through nine checks: the three named choices sit above the boxes, choosing Metric saves and survives a reload, switching replaces the choice, a type alone is kept and tagged without counting as writing, the export carries the types, a wipe and import restores them with newer text kept, an export without types imports and an unknown type is dropped, emptying both boxes keeps the type, and the options wrap at phone width with no sideways scroll. The first screenshots caught the option labels rendering in spaced capitals, because a label rule for the boxes also matched them. That is fixed and the checks were re-run. All passed with no page errors, and the screenshots are attached above.
